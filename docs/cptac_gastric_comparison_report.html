What cptac_gastric does: it is a research-analysis repository for CPTAC Gastric v1.5 data. It loads fixed gastric datafreeze files, runs differential testing, studies glycosylation enzymes and glycoforms, correlates enzymes with glycans, examines PTM crosstalk across phospho/acetyl/ubiquitin/glyco layers, draws circos-style PTM and XL-MS visualizations, and explores gastric cell-state or ecotype-specific signals.

What is redundant: tools/omicsone/diff.py, tools/omicsone/param.py, and the empty tools/omicsone/__init__.py are exact duplicates of current src/omicsone_streamlit/utils/ files. The simple gastric volcano plotting is also mostly subsumed by the current Streamlit volcano page and the newer packaged omicsone.services.volcano_enrichment workflow.

What is new: gastric-specific data loaders, glycosylation enzyme/glycan model helpers, glycoform differential workflows, enzyme-glycan correlation notebooks, PTM circos/crosstalk plotting, XL-MS integration, and KEGG/GPML graph exploration are not first-class features in the current OmicsOne app.

New Gastric Features Worth Considering

FeatureWhy it is newPotential migration target
Gastric data registry and loaders The current repo has generic matrix loading and configured datasets, but not a CPTAC Gastric v1.5 registry covering RNA, CNV, proteome, phosphoproteome, acetylome, ubiquitome, glycoproteome, metadata, enzyme references, and XL-MS. Create src/omicsone/resources metadata or a cohort-specific config file, not hard-coded local paths.

Glycan type classification decide_glycan_type classifies composition strings by fucosylation/sialylation/high-mannose patterns. Add a tested omicsone.services.glyco function with validation for missing composition keys.
Enzyme-glycan correlation workflows The current app supports generic omics correlation, but not glycan-aware enzyme-to-glycoform correlation with glyco pathway annotations. Build on spearman_omics and add glyco-specific annotation and filtering.
Protein-adjusted glycoform differential analysis Several notebooks compare significant glycoform changes with or without corresponding protein abundance changes. Add a paired glyco/protein differential pipeline with explicit outputs for all-glyco/all-protein, all-glyco/protein-no-change, significant-glyco/all-protein, and significant-glyco/protein-no-change modes.
PTM crosstalk circos plots Current pathway scatter handles phosphosite/protein pathway plots, but not per-protein circos tracks integrating phospho, acetyl, ubiquitin, glyco, correlation, and distance links. Implement a plotting service around the reusable parts of ptm.py and crosstalk.py.
XL-MS integration Gastric notebooks and plot_circos_xlms use crosslink data to connect sites on the same gene/protein. Add an XL-MS input schema, validation, and circos plot endpoint if this is a product feature.
KEGG/GPML graph visualization The KEGG notebook explores graph/network extraction with pyvis, separate from the current pathway scatter plot workflow. Consider as a pathway network viewer, but keep separate from existing scatter plots.
